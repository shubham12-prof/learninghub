# Expressions

An expression is any valid unit of code that resolves to a value.

```js
5 + 3; // arithmetic expression -> 8
"a" + "b"; // string expression -> "ab"
x = 10; // assignment expression -> 10
isReady ? "yes" : "no"; // conditional (ternary) expression
```

A **statement** performs an action (like `if`, `for`) and doesn't necessarily produce a value — this distinction is a common interview question.
