# Tips for the Interview

- Always narrate your thought process out loud — interviewers weigh reasoning as much as the final answer.
- When asked to predict output, mentally trace: synchronous code → microtasks (promises) → macrotasks (setTimeout).
- For coding questions, clarify edge cases first (empty input, `null`, duplicate values) before coding.
- If you don't know something, say what you _do_ know and reason toward an answer rather than going silent.
