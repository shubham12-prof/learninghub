## Quick Reference Table

| Pattern           | Time       | Space | Typical Use Case                                   |
| ----------------- | ---------- | ----- | -------------------------------------------------- |
| Interval Problems | O(n log n) | O(n)  | Merging, inserting, removing overlapping intervals |
| Scheduling        | O(n log n) | O(n)  | Activity selection, meeting rooms, job deadlines   |
| Huffman Basics    | O(n log n) | O(n)  | Optimal prefix-free encoding for compression       |

## Suggested Practice Order

1. Interval Problems (sort-then-scan fundamentals)
2. Scheduling (apply interval logic to resource allocation)
3. Huffman Basics (greedy tree-building with a priority queue)
