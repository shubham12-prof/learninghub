# Stack in JavaScript — Learning Guide

Core stack-based patterns for interviews and everyday problem solving.

## Files

1. `01-monotonic-stack.md`
2. `02-parentheses.md`
3. `03-next-greater-element.md`

## Quick Reference Table

| Pattern              | Time | Space | Typical Use Case                                       |
| -------------------- | ---- | ----- | ------------------------------------------------------ |
| Monotonic Stack      | O(n) | O(n)  | Next/previous greater or smaller, histogram problems   |
| Parentheses          | O(n) | O(n)  | Validating, generating, or fixing balanced brackets    |
| Next Greater Element | O(n) | O(n)  | Nearest larger value to the right (linear or circular) |

## Suggested Practice Order

1. Parentheses (intro to stack push/pop logic)
2. Next Greater Element (intro to monotonic stacks)
3. Monotonic Stack (generalize to harder problems like histograms)
